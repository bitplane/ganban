# background save races main-thread mutations

`sync.py:65` — run_sync_cycle runs save_board via asyncio.to_thread while Textual handlers on the main thread freely mutate the same non-thread-safe Node/ListNode structures. No lock or snapshot.

If a sync save iterates board.columns while move_column deletes/re-inserts entries, a column can be skipped from the built tree and its cards silently dropped from the committed state. Verdict: plausible (timing-dependent), but the mechanism is confirmed in code.

Fix idea: snapshot/serialize the tree on the main thread, or guard mutations with a lock — code-only.
