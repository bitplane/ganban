# building collections from live nodes reparents them

`_wrap` (model/node.py) sets `_parent`/`_key` on any Node/ListNode assigned
into another container. Building a temporary collection from live nodes (e.g.
a scratch ListNode to reorder columns) silently reparents them, breaking
watcher bubbling to the real tree. Nothing in production hits it today, but
it's a footgun for any future code (and for ListNode.update called with
shared nodes: the equal-value branch skips reassignment, leaving `_parent`
pointing at the temp container).

Options: only adopt parentless nodes in `_wrap`, or copy-on-adopt, or an
explicit `adopt()` API.
