# remote-merged columns never appear in the TUI

`sync.py:114` — after a remote merge, run_sync_cycle relies on board.update(new_board), but nothing watches board `columns` membership (BoardScreen watches only `sections` and git config, and composes ColumnWidgets once).

A column added remotely is invisible until app restart. Worse, a column archived remotely keeps its stale widget; dropping a card onto it appends to an orphan Node, so the next save writes the card to no column directory — it effectively disappears from the board.
