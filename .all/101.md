# preamble above H1 corrupts card title on round-trip

`loader.py:84` — _build_sections_list applies the fallback title (card id) to any first section with an empty title, but parse_sections emits a synthetic ('', preamble) first section when a card file has text above its H1.

Hand-edit a card to have an intro paragraph above `# Fix login bug` and the next save (auto-sync runs every 30s) serializes `# 001` with the real title demoted to `## Fix login bug` — corruption committed to the branch. Violates the documented clean round-trip.
