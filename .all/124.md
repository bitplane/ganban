# reconcile card widgets inside columns

BoardScreen reconciles ColumnWidgets against board.columns membership, but
ColumnWidget still composes its CardWidgets once and relies on message flows
for changes. A links watcher + reconcile (same pattern as the columns fix)
would make remote card moves/adds/removes fully live inside a column without
restart, and would remove the remaining manual mount/remove paths.
