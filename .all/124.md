# dogfooding

Let's build an app fully agentically using multiple agents on different machines.

1. decide a piece of software to write
2. set up a repo, ganban board with backlog
3. write ganban usage tips into AGENTS.md
4. set up remotes in 4 locations
5. spin up claude, codex, gemini and grok on those boxes

---

I think we'd give each of them their own email address and name, allow comments between then, let them raise their own bugs. Maybe add a way to filter cards in, assign them before picking them up etc.
