# rename transaction

To prevent git from messing things up when we move symlinks about, we need to ensure that certain things are transaction boundaries.

Like renames need to do all the moving around stuff in one commit, because if we combine commits then things lose their history as git does rewrites, and we need to keep the heritage of files if we're going to resolve conflicts properly.

So we need to discuss this and find the cleanest way to support transactions.
