# batch git object writes on save

`writer._hash_object` spawns one `git hash-object` process per card blob, per symlink, and per index.md, plus one mktree per column — hundreds of spawns per save on a real board, every sync cycle. Batch them (e.g. one `git hash-object -w --stdin-paths` invocation, or a single temporary index) without changing the written tree.
