# Propagate pytest failures from the coverage script

scripts/coverage.sh:9-15 pipes pytest through tee without checking pytest status, then ends with grep ... || true.

Failure scenario: pytest reports a failing regression test, but scripts/coverage.sh exits zero and the documented make coverage/default make verification can report success. CI make test uses a different script.

Expected: preserve and return pytest failure status while still producing reports. Merely enabling pipefail without exiting or explicitly returning the captured status is insufficient because the final grep command masks failure again.
