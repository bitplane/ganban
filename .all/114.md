# shared bases for tag editors and add widgets

- `DepsWidget` copy-pastes ~110 lines of `LabelsWidget` (_rebuild_tags, _current_*_except, on_click routing, _add_new_tag, tag message handlers) with only the meta key and option builder varying
- `UsedLabelRow` copy-pastes `SavedLabelRow` with only the trailing button differing
- six near-identical "plus" add-widgets (AddCard, AddColumn, AddSection, AddKeyRow, AddUserRow, AddLabelRow) re-implement the same EditableText flow
