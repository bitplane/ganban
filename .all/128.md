# Prevent right-arrow crash at the last column

src/ganban/ui/column.py:247-252 includes AddColumn in horizontal navigation siblings and calls find_nearest on it. AddColumn has no such method.

Reproduction: focus a card, column title, or add-card control in the last column and press Right. The TUI raises AttributeError.

Expected: horizontal navigation remains within actual board columns and safely stops at either edge. Verify with real Textual key events and retain navigation between columns.
