# Prevent right-arrow crash at the last column

src/ganban/ui/column.py:247-252 includes AddColumn in horizontal navigation siblings and calls find_nearest on it. AddColumn has no such method.

Reproduction: focus a card or add-card control in the last column and press Right. The TUI raises AttributeError.

Expected: horizontal navigation remains within actual board columns and safely stops at either edge. Verify with real Textual key events and retain navigation between columns.

## Resolution

Fixed in code commit 7012949. Horizontal arrow navigation selects actual ColumnWidget siblings, excluding AddColumn and other controls. Focus stays at the edge.

Reproduced the exact AttributeError with real Textual key events before the fix. Regression tests cover cards and add-card controls at both edges and navigation between columns. Focused UI tests: 11 passed. Full suite: 731 passed. Commit hooks passed.
