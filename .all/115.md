# node and UI plumbing cleanups

- `ListNode._items` is fully derivable from `_by_id` (dicts preserve insertion order); dual mutation needs the O(n) `_key_index` scan
- Node and ListNode duplicate identical `watch()` and `path` implementations
- `CardWidget.MoveRequested` carries the column display title and the screen resolves it by title equality; pass the column identity instead (breaks with duplicate names)
- `CardDetailModal` hand-rolls `watch`/unwatch/on_unmount instead of using `NodeWatcherMixin`
