# avoid redundant work in load and cli sync

- `loader._get_committers` walks up to 100 commits across all refs on every `load_board`, including one-shot CLI commands that never use committer data — make it lazy or TUI-only
- `cli/sync._do_sync` calls `load_board` up front and again for every remote with a ganban branch, even when no merge is needed — reload only after a merge
